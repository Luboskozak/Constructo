# Constructo

Web aplikace Constructo (mobil v kořeni, počítač v /pc). Netlify ji zveřejní automaticky po každé změně ve větvi main.

Nasazování: Claude ukládá změny pod účtem Luboskozak (jediný přispěvatel, bezplatný plán Netlify).


Dokumentace (od 4.52): kód v pc/dokumentace.js (záložka v /pc i stránka /dokumentace/, kterou ukazuje Deník), data D.dokumenty,
soubory na Disku Google přes skript Google (akce dok_start / dok_cast / dok_cti / dok_smaz, od verze skriptu 13).
Knihovny: dokumentace/pdfjs (PDF.js, Apache-2.0), dokumentace/dwg (LibreDWG, GPL-3.0, jen převod DWG v samostatném vlákně).
