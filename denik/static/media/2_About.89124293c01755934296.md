
# O systému

Constructo je moderní systém pro sdílení a předávání informací napříč procesem stavby a stavebním řízením. Podporuje sdílení medií a denních záznamů stavebního deníku. Ačkoliv naše snaha je aby byl systém co nejvíce uživatelsky přívětivý, jsme si vědomi, že možná narazíte na nejasnosti. Z tohoto důvodu jsme pro vás připravili nápovědu.
