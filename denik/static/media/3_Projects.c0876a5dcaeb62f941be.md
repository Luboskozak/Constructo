
# Projects

## Description

Projects are base units within the system. You can imagine it as a building of house or construction of industry hall. Anything which can fit the set a processes.
Each project can have as many users as needed although it may be limited by the amount your subscription plan offers or by the amount of users you bought.
Same goes for the cloud storage where we set base limit but you are free to extend this space any time you need.

## Project creation

For creation of the new Project:

1. Click on the `Home` button in the corner of the screen.
2. Click on the `+` button.
3. Fill the General and Management columns and be sure that your project has at least approximate location.
4. Do not fill the users and click the `Save` button.

After successfull creation of the record you are becoming the Project creator which is role with highest access and operational rights.

## Set up active project

The app itself depends on which project is set as an active. For example if you build two houses you should have two projects for these houses and switch between them. With this you can be sure that the context of both is not mixed.
For switching between projects:
1. Go to Project list by clicking on `Home`.
2. Select the project you want to work on by clicking on `Set` button. 

## Project detail and editing

Every time you need to see the details about the project you can access it by set of steps:
1. Go to Project list by clicking on `Home`.
2. Select the project you want to see details of on by clicking on on the line with the project.

Note: It may happen that this operation is not available for you due to your role on the project. If that happens please contact your project creator.

## Project deletion

Only project creators can delete projects. This function is available only in the web app.

Note: It may happen that this operation is not available for you due to your role on the project. If that happens please contact your project creator.

## Project users and roles

Each project can have assigned multiple users. For example one user is architect, second is manager, third is owner, fourth is supplier and so on.

### Adding of the user from project detail

For adding of the user to the project follow these steps:
1. In navigation bar click on `Home` button.
2. Choose the project by tapping on the line.
3. Click on `Management` button.
4. In Users section tap on `Add`
5. Fill the email.
6. Tap on `Add` button.

If the user is registered within the system already, you would see his name in the list below.
If the user is not yet registered you would see his email until he would register and set his project as active.

Note: It may happen that this operation is not available for you due to your role on the project. If that happens please contact your project creator.

### Removing of the user

Removing of the user is just as easy and straightforward:
1. In navigation bar click on `Home` button.
2. Choose the project by tapping on the line.
3. Click on `Management` button.
4. Swipe on the line with the user you want to delete.
5. Click on the `X` button.

Note: It may happen that this operation is not available for you due to your role on the project. If that happens please contact your project creator.

### Set up role for the user

Each user can have one role on the project. Role may differ with his access rights specified with each rule.
For set up of the role for the user do following:
1. In navigation bar click on `Home` button.
2. Choose the project by tapping on the line.
3. Click on `Management` button.
4. Tap on the yellow name of the role which is in the line for the user.
5. Tap on the role you want to set for the user

Note: It may happen that this operation is not available for you due to your role on the project. If that happens please contact your project creator.

### Create a new role

For creation of the role for the user do following:
1. In navigation bar click on `Home` button.
2. Choose the project by tapping on the line.
3. Click on `Management` button.
4. Tap on the `Configure roles` button.
5. Tap on the `+` button.
6. Fill the form.
7. Tap on the save button.

Note: It may happen that this operation is not available for you due to your role on the project. If that happens please contact your project creator.

### Delete the role

For deletion of the role for the user do following:
1. In navigation bar click on `Home` button.
2. Choose the project by tapping on the line.
3. Click on `Management` button.
4. Tap on the `Configure roles` button.
5. Swipe on the line with the role.
6. Tap on icon for deletion.

Note: It may happen that this operation is not available for you due to your role on the project. If that happens please contact your project creator.
