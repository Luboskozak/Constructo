
# Files

With files you can simulate archive and storage of blueprints and all crucial data. Files are store in Europe data centers so no need to worry about privacy.

## Creation of the folder

For creation of the folder follow these steps:
1. Go to files section by clicking on `Files` button in the left navigation bar.
2. Click on `Create Folder` button in the left corner.
3. Type the name of the folder.
4. Confirm by clicking on the `Confirm` button.

Note: It may happen that this operation is not available for you due to your role on the project. If that happens please contact your project creator.

## Deletion of the folder

For creation of the folder follow these steps:
1. Go to files section by clicking on `Files` button in the left navigation bar.
2. Click on `Delete` button. Please be noted that only empty folders can be deleted.

Note: It may happen that this operation is not available for you due to your role on the project. If that happens please contact your project creator.

## Uploading a file

For uploading of the files follow these steps:
1. Go to files section by clicking on `Files` button in the left navigation bar.
2. Select folder in which you would like to store the files.
3. Click on `Add File` button.

Note: It may happen that this operation is not available for you due to your role on the project. If that happens please contact your project creator.

## Deleting the file

For creation of the folder follow these steps:
1. Go to files section by clicking on `Files` button in the left navigation bar.
2. Click on `Delete` button.

Note: It may happen that this operation is not available for you due to your role on the project. If that happens please contact your project creator.

## Versions of files

Each file can have multiple versions:
1. Open your list of files by clicking on  `Files` in the left navigation bar.
2. On specified file (not folder) click on details `Details`.
3. The window shows details about files, click on tab `Versions`.
4. Active version is marked with yellow dot. You can set any of the versions as active.
5. You can upload new version or delete version by clicking on buttons in the window.
6. After you set up active version this version will be always shown and downloaded.

Note: It may happen that this operation is not available for you due to your role on the project or purchased plan. If that happens please contact your project creator.
